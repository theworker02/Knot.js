# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in Knot.js a harassment-free experience for everyone.

## Our standards

Examples of behavior that contributes to a positive environment:

- Demonstrating empathy and respect
- Giving and gracefully accepting constructive feedback
- Focusing on what is best for the community
- Accurately describing security and compatibility limitations

Examples of unacceptable behavior:

- Harassment, trolling, or derogatory comments
- Publishing others' private information
- Submitting known-malicious packages or exploit proofs against users

## Enforcement

Report incidents to the maintainers via GitHub Security advisories or the contact listed in `SECURITY.md`. Maintainers will review and respond as appropriate.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
