# Introduction

Knot.js is a content-addressed dependency execution framework.

It does not try to be a prettier npm client. It asks whether JavaScript applications can stop installing dependency trees entirely.

A Knot-native project declares the packages it is allowed to use. Knot resolves, retrieves, verifies, stores, and executes them. The same immutable object can be reused by every project on the machine.

See [Why Knot?](why-knot.md) and the [quick start](quick-start.md).
